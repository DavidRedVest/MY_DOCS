# OmniLink-Edge：端边协同工业测控系统

> **架构形态：** PC 上位机 + 嵌入式主控 + 多路工业传感器

## 1. 项目背景与目标

针对工业现场多类型传感器接入复杂、实时性要求高的场景，构建一套从底层传感器数据采集、主控逻辑调度到 PC 端实时监控与参数下发的完整本地闭环系统。

## 2. 核心技术栈

- **嵌入式主控端：** C / C++、RTOS 实时任务调度、Modbus (RS485) / CAN 现场总线协议栈
- **PC 上位机端：** 跨平台 GUI 界面、串口/网口高速数据收发、实时波形绘制与数据持久化
