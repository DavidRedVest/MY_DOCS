# OmniLink-Core：嵌入式 Linux 工业互联底座

> **架构形态：** 嵌入式 Linux 网关 / 边缘计算终端

## 1. 项目背景与目标

面向算力更强、业务更复杂的工业边缘网关硬件，基于嵌入式 Linux 构建高可靠、模块化的设备管理核心软件底座，统一底层硬件抽象与上层业务接口。

## 2. 核心技术栈

- **系统与底层：** 嵌入式 Linux 系统定制、设备树与外设驱动适配、守护进程（Daemon）管理
- **中间件与运维：** 多进程通信（IPC / Unix Domain Socket）、远程日志诊断、双分区安全 OTA 升级
