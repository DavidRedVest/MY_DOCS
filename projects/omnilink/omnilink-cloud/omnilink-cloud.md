# OmniLink-Cloud：云边互联与可视化管理平台

> **架构形态：** 工业物联网关 + 云端服务 + 跨平台 GUI 监控终端

## 1. 项目背景与目标

在本地测控基础上引入广域网通信与云端管理能力，解决分布式多站点设备的统一接入、状态遥测、告警推送与跨终端可视化运维问题。

## 2. 核心技术栈

- **网络与通信层：** TCP/IP 长连接保活、MQTT / 自定义二进制网关协议、断网重连与本地缓存补传
- **云端与 GUI 端：** 设备影子状态机、高并发消息路由、跨平台桌面/可视化监控界面
